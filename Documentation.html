HTML5 Bootstrap 5 SCSS Vanilla JavaScript Vite

1. Introduction

Nexora is a modern HTML website theme designed for business websites, agencies, creative studios, and service providers. Its source files are organized to help developers customize layouts, styles, and content.

What is included?

  • HTML page templates.
  • SCSS stylesheets for styling customization.
  • JavaScript files for interactive elements.
  • Image assets used by the website.
  • Bootstrap-based layout and responsive utilities.
  • This documentation file.
Important Nexora is an HTML theme, not a WordPress theme. It does not include a WordPress installation, PHP backend, database, or content management dashboard.

2. Requirements

To edit the source files and run the development server, you will need the following software.

If you only want to view a previously built website, you may be able to open its HTML files directly. For development, use the Vite workflow described below.

3. Installation

Step 1 — Extract the package

Extract the Nexora ZIP package into a folder on your computer. Open the extracted project folder in Visual Studio Code.

Step 2 — Install Node.js

If Node.js is not already installed, download and install the current LTS version from the official website.

Visit the official Node.js website →

Step 3 — Open the terminal

In Visual Studio Code, open the project folder and select Terminal → New Terminal.

Step 4 — Install dependencies

Terminalnpm install

Run this command from the folder containing the project's package.json file.

Step 5 — Start the development server

Terminalnpm run dev

Open the local URL displayed in your terminal. Vite commonly uses http://localhost:5173, but the actual URL may differ.

Step 6 — Build for production

Terminalnpm run build

If the project has a configured build script, Vite generates production files in the configured output directory, commonly named dist.

Check your package.json The available commands depend on the scripts included in the delivered project. Confirm that the dev and build scripts exist before running them.

6. Colors & Typography

Nexora uses a centralized SCSS approach for consistent styling. When available, edit the existing design tokens instead of creating duplicate global rules.

Brand color reference

Token Example value Purpose
$nx-primary #2563EB Primary buttons, links, and accents.
$nx-dark #0F172A Headings and dark elements.
$nx-body #475569 Body text.
$nx-muted #64748B Secondary text.
$nx-border #E2E8F0 Borders and dividers.

These values are reference tokens. Their exact variable definitions and file locations must match the delivered source code.

How to customize colors

  1. Open the SCSS variables file used by the project.
  2. Locate the relevant design token.
  3. Change its value to your preferred brand color.
  4. Restart or refresh the development preview if necessary.
  5. Test all pages and responsive layouts.

Typography

Typography may be controlled through SCSS variables or global styles. Update the font family, size, weight, and line height in the appropriate source file. If the font is loaded from an external service, ensure that the font URL remains valid.

7. Content & Images

9. Responsive Layout

Nexora is designed to adapt to different screen sizes. Always test your changes on desktop, tablet, and mobile devices before deploying the website.

Viewport Recommended check
320 × 568 Small mobile screens and horizontal overflow.
375 × 812 Common mobile layout and text wrapping.
768 × 1024 Tablet spacing, columns, and navigation.
1440 × 900 Desktop content width and section alignment.

Responsive customization tips

  • Use the existing media queries where possible.
  • Avoid fixed widths that cause horizontal scrolling.
  • Check heading wrapping and image cropping.
  • Verify button spacing and navigation behavior.
  • Retest shared components after changing global styles.

10. Troubleshooting

Issue Possible solution
Dependencies fail to install Check Node.js and npm versions, internet connectivity, and the terminal's current folder.
Development server does not start Check package.json, the available scripts, and terminal error messages.
Images are missing Verify filenames, capitalization, asset locations, and image paths.
Styles do not update Check SCSS imports, stylesheet loading, build errors, and browser caching.
Icons do not appear Check whether the icon package is installed and its CSS is imported.
Mobile layout overflows Inspect fixed widths, long text, image dimensions, and media queries.
Page links do not work Verify the destination filename and link path.

Before requesting support

Include the page name, the steps that reproduce the issue, the browser you are using, and any relevant error messages. This information makes troubleshooting easier.
